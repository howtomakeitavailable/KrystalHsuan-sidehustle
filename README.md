# Krystal 書頁工作室：接案 Dashboard

書籍排版・校對・翻譯的接案網站。網站本身是純靜態網頁，可以免費放在 GitHub Pages；「後台」用一份 Google 試算表，不用架伺服器、不用付費。

| 分頁 | 網址 | 內容 |
| --- | --- | --- |
| 收費與規則 | `#rules` | 服務介紹、關於我、價目表、急件／折扣／訂金、合作流程、條款 |
| 作品集 | `#portfolio` | **文件檢視**（仿 Word：尺規、縮放、修訂標示、字數統計）與**翻頁檢視**（3D 翻書） |
| 委託試算 | `#quote` | 案主填單時即時算出金額、訂金、工作天，並判斷交件日趕不趕得上 |
| 檔期行事曆 | `#schedule` | 時間軸與月曆兩種檢視，顯示手上每件案子從開工到截稿的區塊 |

```
            案主看到的（前台）                         你管理的（後台）
┌──────────────────────────────┐      ┌─────────────────────────────────┐
│ GitHub Pages 網站             │      │ Google 試算表                    │
│  委託試算 ── 送出 ───────────────────▶ 「委託」分頁（含案主個資，只有你看得到）│
│                               │      │        │ 你點「接案 → 排入檔期」   │
│  檔期行事曆 ◀── 讀取 ───────────────── 「檔期」分頁（只有公開欄位）        │
└──────────────────────────────┘      └─────────────────────────────────┘
                                              ＋ 每筆新委託寄信通知你
```

## 第一步：換成你的資料

打開 `assets/js/config.js`，照順序改這幾個區塊（網頁上看到的文字幾乎都在這裡）：

| 區塊 | 要改什麼 |
| --- | --- |
| `site` | 工作室名稱、你的名字、一句話介紹、Email |
| `about` | 規則頁的「關於我」：大頭照、自我介紹、經歷／工具／語言 |
| `capacity` | 同時可接幾件（`maxConcurrent`）、休假日（`daysOff`） |
| `pricing` | 所有單價、每日產能、急件級距、折扣、最低收費、訂金比例 |
| `rules` | 合作流程與條款文字 |

改完存檔，用瀏覽器重新整理 `index.html` 就看得到。

**大頭照**：把照片放進 `assets/img/`，例如 `assets/img/me.jpg`，再把 `about.photo` 改成 `'assets/img/me.jpg'`。正方形、500×500 左右就夠了。

**每日產能（`perDay`）很重要**：它決定試算出來的工作天，以及交件日會不會被判成急件。建議拿你最近幾個案子實際花的天數回推：例如 9 萬字的一般校對做了 5 天，每天就是 18,000 字。

> 小提醒：`config.js` 是程式檔，改文字時保留前後的引號 `'…'` 和結尾的逗號。改壞了網頁會變空白，這時把最後改的地方還原就好。

## 第二步：放入你的作品集

每本書是 `portfolio` 裡的一筆。有兩種放法，可以混用。

### 方法 A：整頁圖片（推薦，排版作品用這個）

直接展示你實際排好的版面，最能呈現排版功力。

1. **匯出頁面圖**
   - InDesign：「檔案 → 轉存 → 格式選 JPEG」，範圍選要展示的頁面，**轉存為「頁面」不是「跨頁」**，解析度 150 ppi、品質「高」。
   - 只有 PDF：Acrobat「匯出 PDF → 影像 → JPEG」；沒有 Acrobat 的話可以用免費的 [iLovePDF](https://www.ilovepdf.com/zh-tw/pdf_to_jpg)。
2. **挑 8～16 頁**：封面、目次、章首頁、內文頁、圖文頁各挑幾張。第 1 張會當成封面。
3. **放進資料夾**：例如 `assets/img/island/`，檔名改成 `p01.jpg`、`p02.jpg`……
4. **在 config.js 加一筆**：
   ```js
   {
     id: 'island',
     title: '島嶼慢讀',
     kind: '散文集',
     role: '排版＋一校',
     year: 2025,
     trim: [148, 210],            // 成品尺寸 mm，決定頁面比例
     coverColor: '#34505e',       // 作品按鈕上書背的顏色，挑封面主色
     note: '25 開、內文 10.5pt、行距 1.75。',
     scans: { folder: 'assets/img/island', count: 12 }
   },
   ```
   檔名不想改的話，可以改成列出檔名：`scans: { folder: 'assets/img/island', files: ['封面.jpg', '目次.jpg', '內文1.jpg'] }`。

### 方法 B：用文字重現（校對、翻譯作品用這個）

校對與翻譯的價值在「改了什麼」，用文字呈現比截圖清楚。目前 `config.js` 裡的三本範例都是這種寫法，照著改就好：

- **校對示範**：在內文用 `[-刪掉的字-]` 和 `{+加上的字+}`，文件檢視打開「顯示修訂」就會出現紅色刪除線和藍色底線。建議挑一段 300～500 字、修改密度高的段落。
- **翻譯示範**：用 `bilingual` 頁面，放 2～4 組原文與譯文對照。
- 其他頁面類型：`cover`（封面）、`toc`（目次）、`chapter`（章首）、`text`（內文）、`image`（插圖＋圖說）、`blank`（空白頁）。

### 關於授權

放進作品集之前，請先確認出版社或作者同意公開。未出版的書，可以只放封面加兩三頁內文，或把人名、書名換掉。

## 第三步：設定後台（Google 試算表）

做完之後，你的日常管理都在試算表裡，手機上也能用 Google 試算表 App 操作，不用碰程式。

### 一次性設定（約 10 分鐘）

1. **建立試算表**：到 [sheets.new](https://sheets.new) 開一份新的，取名例如「接案後台」。
2. **貼上程式**：選單「擴充功能 → Apps Script」，把編輯器裡原本的內容全部刪掉，貼上本 repo 的 `backend/google-apps-script.gs`，按儲存（磁碟片圖示）。
3. **建立分頁**：上方函式下拉選單選 `setup`，按「執行」。
   - 第一次會要求授權：選你的帳號 →「進階」→「前往（不安全）」→「允許」。會出現「未驗證」是因為這是你自己寫的程式，不是公開 App，可以放心。
   - 回到試算表，會多出「委託」和「檔期」兩個分頁。
4. **部署成網址**：Apps Script 右上角「部署 → 新增部署作業」→ 齒輪選「網頁應用程式」：
   - 執行身分：**我**
   - 誰可以存取：**所有人**（網站需要讀檔期、送委託；「委託」分頁不會被讀到）
   - 按「部署」，複製「網頁應用程式網址」（結尾是 `/exec`）。
5. **接到網站**：把網址貼進 `config.js` 的 `site.backendUrl`：
   ```js
   backendUrl: 'https://script.google.com/macros/s/AKfy…/exec',
   ```
6. **測試**：用網站送出一筆測試委託，確認「委託」分頁多了一列、信箱收到通知信。

> 之後如果修改了 Apps Script 程式，要到「部署 → 管理部署作業 → 編輯（鉛筆）→ 版本選『新版本』→ 部署」才會生效，網址不變。只改試算表內容不需要重新部署。

### 日常流程

1. **收到委託**：信箱收到通知信，試算表「委託」分頁多一列，狀態是「待回覆」。直接回覆通知信就會寄給案主。
2. **回覆報價**：把狀態改成「已報價」。
3. **案主付訂金、委託成立**：在「委託」分頁點那一列，選單「接案 → 把選取的委託排入檔期」。
   - 會自動在「檔期」分頁新增一列（代稱「案主A、B、C…」），狀態改成「成立」。
   - 到「檔期」確認開工日、截稿日，把「工作內容」改成你想公開的描述（例如「心理學譯著 二校」）。這欄會出現在網站上，不要寫書名或作者名。
4. **網站自動更新**：重新整理網站，行事曆和側欄的「可接新案／檔期已滿」就會更新。

「檔期」分頁的欄位：

| 欄位 | 說明 |
| --- | --- |
| 代稱 | 網站上顯示的名稱 |
| 服務 | 排版／校對／翻譯（下拉選單） |
| 工作內容 | 公開的簡短描述 |
| 開工日、截稿日 | 日期格式 `2026-10-05` |
| 洽談中 | 打勾＝虛線顯示、不佔檔期（還沒付訂金時用） |
| 隱藏 | 打勾＝不在網站上顯示 |

也可以不透過委託，直接在「檔期」分頁手動加一列，例如熟客私下找你的案子。

### 不想用試算表的話

- **只要收信**：`backendUrl` 留空，`formEndpoint` 填 [Formspree](https://formspree.io) 的表單網址（免費每月 50 筆）。檔期則在 `config.js` 的 `projects` 手動維護。
- **兩個都留空**：案主送出後會拿到整理好的委託內容，自己複製寄信給你。

## 第四步：上線（GitHub Pages）

1. 到 repo 的 **Settings → Pages**。
2. Source 選 **Deploy from a branch**，Branch 選 `main`、資料夾 `/ (root)`，按 Save。
3. 約一分鐘後會出現網址，例如 `https://<帳號>.github.io/KrystalHsuan-sidehustle/`。

之後改了 `config.js` 或新增作品圖片，推上 `main` 就會自動更新。檔期只要改試算表，不需要重新推。

## 試算怎麼算

1. 各項服務依單價算小計（排版每頁、校對每千字 × 校次倍率、翻譯每字 × 文類倍率）。
2. 同時委託兩項以上，小計打折（`comboDiscount`）。
3. 預估工作天 = 數量 ÷ 每日產能（`perDay`）。
4. 開工日取「明天」「原稿可給日」「你的下一個空檔」三者最晚的一天。
5. 開工日到交件日的可用工作天 ÷ 預估工作天，對照 `rush` 級距決定一般件／急件／特急件；低於最低級距就提示「時程不足，需要另外討論」。
6. 套用最低收費，金額取整到 10 元，並列出訂金。

## 檔案結構

```
index.html                   四個分頁的骨架
assets/css/style.css         樣式（含深色模式）
assets/js/config.js          ← 你會改的內容都在這裡
assets/js/app.js             試算、行事曆、作品集的程式
assets/img/                  大頭照、作品集圖片
backend/google-apps-script.gs  貼到 Google 試算表的後台程式
```
